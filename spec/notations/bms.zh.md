# BMS（Bashicu Matrix System）多版本计算规则

> **Source / 源文章**：`study/notations/BMS.md`
> **Creator / 创造者**：Bashicu（初版 BM1）；库实现 `creator()` 待用户在计划模程确认后回填（当前 BMS 基类与各子类 `creator()` 默认 `""`，见 `doc/api/bms.zh.md`）。
> **Version / 版本**：BM1=2014，BM2=2016，BM2.3/BM4=2018，BM3.3=2019；库以子类区分，`version()` 待补。
> **记号类别**：序数记号（矩阵 → 序数，经 `Trans()` 映射）。库只展开一步、不求值，故**终止性 / 良基性被刻意忽略**（用户指令：把良基丢进垃圾桶）。
> **库实现映射**：基类 `BMS`（§0 共用骨架）+ 子类 `BM4` / `BM1` / `BM3.3`（差异钩子 `parentOf` / `ascensionDegree`）；其余版本因 $a_{k,m}$ 精确公式仅见于 basmat 源码、公开文档未给，暂不接入（见 `doc/api/bms.zh.md`）。

记号：列标 $x$、行标 $y$（从 $0$ 起）。$S=S_0S_1\cdots S_{X-1}$（$X$ 列）；列 $S_x=(S_{x,0},\dots,S_{x,Y-1})$。$S_{x,y}$ 为第 $x$ 列第 $y$ 行元素。$S+T$ 为列拼接。末列 $S_{X-1}$；其最靠下非零元素所在行 $z=\max\{y\mid S_{X-1,y}>0\}$（该元素称 LNZ）。

# 0. 共用展开骨架（BM4 标准；其余版本共用）

# 0.1.定义
合法矩阵（标准型）满足：
1. 首列全 $0$：$S_{0,y}=0$；
2. 每列自上而下非增：$S_{x,y}\ge S_{x,y+1}$；
3. 同行不超前超 $1$：$S_{x,y}\le \max_{p<x}S_{p,y}+1$（空最大值为 $0$）。

# 0.2.展开

## 0.2.1 辅助函数
1. **父项** $p_k(m)$：取满足
   $$S_{p,k}<S_{m,k}\quad\text{且（}k>0\text{ 时）}\quad a_{k-1,m}(p)=1$$
   的最大 $p<m$。其中 $a_{k-1,m}(p)=1\iff\exists c\ge0:(p_{k-1})^c(m)=p$（列 $p$ 是列 $m$ 在 $k-1$ 行下的祖先）。约定 $(p_k)^0(m)=m$。
2. **上升度** $a_{k,m}(t)$：对坏部第 $m$ 列（$t$ 为坏根列标），
   $$a_{k,m}(t)=\begin{cases}1,& \exists c\ge0:(p_k)^c(m)=t\\0,& \text{否则}\end{cases}$$
3. **坏根** $r=p_z(X-1)$（末列 LNZ 的父项）；末列全 $0$ 则无坏根。
4. **好部 / 坏部**：$G=S_0+\cdots+S_{r-1}$，$B=S_r+\cdots+S_{X-2}$。
5. **阶差** $\Delta_k=\begin{cases}S_{X-1,k}-S_{r,k},& k<z\\0,& k\ge z\end{cases}$。
6. **副本** $B^{(i)}$ 第 $m$ 列：$B^{(i)}_{m,k}=B_{m,k}+a_{k,r+m}(r)\cdot\Delta_k\cdot i$。

## 0.2.2 expand 函数
$$
\begin{aligned}
\mathit{expand}((),n)&=n\\
\mathit{expand}(S+(0),n)&=\mathit{expand}(S,2n)\\
\mathit{expand}(S,n)&=\mathit{expand}\bigl(G+B^{(0)}+\cdots+B^{(n)},\;2n\bigr)\quad(\text{末列非全 }0)
\end{aligned}
$$
基本列前驱 $FS_n(S)=G+B^{(0)}+\cdots+B^{(n-1)}$。序数映射：
$$
\mathit{Trans}()=0,\quad \mathit{Trans}(S+(0,\dots,0))=\mathit{Trans}(S)+1,\quad \mathit{Trans}(M)=\sup\{\mathit{Trans}(FS_i(M))\mid i\in\mathbb N\}.
$$
**库约定**：`expand(n)` 只产出第 $n$ 项基本列 $FS_n(S)$（一步展开，与 Prss / EpspSS 一致），不递归迭代、不求值。

# 1. BM1（初版，2014）
# 1.1.定义
同 §0.1。
# 1.2.展开
## 1.2.1 辅助函数
父项 $p_k(m)$（$k>0$）**缺上行祖先检查**（即 $a_{k-1,m}(p)=1$ 条件不生效），退化为仅按首行判定。上升度由首行统一决定：
$$a_{k,m}(t)=a_{0,m}(t)\quad(\forall k)$$
（各行的祖先链判定被忽略，只用首行父项链。）
## 1.2.2 expand 函数
同 §0.2.2。
终止性：否。

# 9. BM3.3（Rpakr + ecl1psed，2019）
# 9.1.定义
同 §0.1。
# 9.2.展开
## 9.2.1 辅助函数
与 BM4 唯一差异在上升度。设 $t=$ 坏根列 $r$（上升度目标）。坏部各列分两类：
- **第 $t$ 行是坏根 $r$ 的后代（含 $r$ 本身）的列**：前 $t-1$ 行 $a_{k,m}$ 全为 $1$（与 BM4 相同）。
- **第 $t$ 行不是坏根后代的列**：
  $$\text{BM4}:\quad a_{k,m}=1\iff a_{k,\mathrm{parent}(m)}=1\ \land\ (\mathrm{parent}=r\ \lor\ \mathrm{parent}>r)$$
  $$\text{BM3.3}:\quad a_{k,m}=1\iff a_{k,\mathrm{parent}(m)}=1\ \land\ \mathrm{parent}>r$$
  （BM3.3 去掉了"父项 = 坏根"这一条件。）
## 9.2.2 expand 函数
同 §0.2.2（仅上升度按 9.2.1）。终止性：未证明。
示例：$(0,0,0)(1,1,1)(2,1,0)(1,1,1)$ 在 BM3.3 下展开首项为
$$(0,0,0)(1,1,1)(2,1,0)(1,1,0)\dots$$

# ε_pSS / ε_ωSS — 逐公式演算跟踪 (Worked Examples)

> 本文档**不是**规范说明，而是把 `epsilon_ss.zh.md` / `epsilon_ss.en.md` 中
> 文章的 **expand 公式** 应用到具体输入、逐步手算的跟踪记录，用于核对
> C++ 参考实现（以及未来 C / Java / Python / Lean4 移植）是否严格照文章执行。
> 全部计算均按文章原文，无额外见解。

> 记号（与文章一致）：
> - `A=(a₁,…,aₙ)`；空序列 `()`。
> - `br = max{n−i ∣ a_{n−i} < aₙ}`（最右比 `aₙ` 小的列标，1-based）= 代码 `rightmostLess_(aₙ)`。
> - `L = n − br`。
> - `q = aₙ − a_{br}`（注意 `a_br` 是位置 `br` 的元素）。
> - `expand(A,m>0) = expandLen(A, m·L − 1)`；`expand(A,0) = expandLen(A,0)`（末位 −1）。
> - `expandLen(A,k)` 的每一步 `s=1..M` 追加一个元素，取自**运行序列** `expandLen(A,k)` 在阶段 `k=s−1` 的第 `X` 项（非原 `A`），并按 case 加 `add`：
>   - case 2 (`aₙ=a_k+1`)：`X = s+n−L`，`add = 0`。
>   - case 3 (`aₙ=a_k+q`)：`X = n+s−1`，`add = q−1`。
>   - case 4 (仅 ε_pSS，`aₙ−a_k>p`)：`X = n+s−1`，`add = p`。
> - 后继 `A=(…,1)`：`expand` / `expandLen` 一律剥去尾 1。

---

## 1. ε_pSS（有参数 `p`，含 case 4）

### 1.1 后继：`A=(1,2,1)`（p 任意）
- 末位为 1 → 剥尾 1。
- `expand(A,m) = (1,2)`（任何 `m`）。

### 1.2 case 2 (`q=1`)：`A=(1,2)`, `p=2`
- `n=2`；`rightmostLess_(2)` 在位置 1（值 1）< 2 → `br=1`；`L=2−1=1`；`q=2−1=1` → case 2。
- `expand(A,1)`：`M=1·1−1=0` → `expandLen(A,0)=(1,1)`。
- `expand(A,2)`：`M=2·1−1=1`。
  - 末位 −1：`(1,1)`。
  - `s=1`（case 2）：`X=1+2−1=2`，运行序列 `[1,1]` 第 2 项 = 1，`add=0` → 追加 **1** → `(1,1,1)`。
- 结果：`expand(A,2) = (1,1,1)`。

### 1.3 case 3 (`1<q≤p`)：`A=(1,1,3)`, `p=2`
- `n=3`；`rightmostLess_(3)` 在位置 2（值 1）< 3 → `br=2`；`L=3−2=1`；`q=3−1=2`，`2≤p=2` → case 3，`add=q−1=1`。
- `expand(A,0)`：`(1,1,2)`。
- `expand(A,1)`：`M=1·1−1=0` → `(1,1,2)`。
- `expand(A,2)`：`M=1`。
  - 末位 −1：`(1,1,2)`。
  - `s=1`（case 3）：`X=3+1−1=3`，运行序列 `[1,1,2]` 第 3 项 = 2，`add=1` → 追加 **3** → `(1,1,2,3)`。
- 结果：`expand(A,2) = (1,1,2,3)`。
- （`p=5` 时 `q=2≤5` 同样走 case 3，结果相同。）

### 1.4 case 4 (`q>p`)：`A=(1,4)`, `p=1`
- `n=2`；`rightmostLess_(4)` 在位置 1（值 1）< 4 → `br=1`；`L=2−1=1`；`q=4−1=3`，`3>p=1` → case 4，`add=p=1`。
- `expand(A,1)`：`M=1·1−1=0` → `(1,3)`。
- `expand(A,2)`：`M=1`。
  - 末位 −1：`(1,3)`。
  - `s=1`（case 4）：`X=2+1−1=2`，运行序列 `[1,3]` 第 2 项 = 3，`add=1` → 追加 **4** → `(1,3,4)`。
- `expand(A,3)`：`M=2`。
  - 末位 −1：`(1,3)`。
  - `s=1`（case 4）：`X=2`，`seq[1]=3`，`+1` → 追加 **4** → `(1,3,4)`。
  - `s=2`（case 4）：`X=2+2−1=3`，运行序列 `[1,3,4]` 第 3 项 = 4，`add=1` → 追加 **5** → `(1,3,4,5)`。
- 结果：`expand(A,3) = (1,3,4,5)`。

### 1.5 case 3 与 case 4 的封顶差异：`A=(1,4)`, `p=4`（对照 1.4）
- `q=3`，`3≤p=4` → **case 3**，`add=q−1=2`（而非 case 4 的 `p=4`）。
- `expand(A,2)`：`M=1`。末位 −1 `(1,3)`；`s=1`（case 3）：`X=2`，`seq[1]=3`，`+2` → 追加 **5** → `(1,3,5)`。
- `expand(A,3)`：`M=2`。`s=1` → `X=2`，`3+2=5` → `(1,3,5)`；`s=2` → `X=3`，运行 `[1,3,5]` 第 3 项 = 5，`+2` → 追加 **7** → `(1,3,5,7)`。
- 结果：`expand(A,2)=(1,3,5)`，`expand(A,3)=(1,3,5,7)`。
- 印证：同样输入 `(1,4)`，`p=1` 走 case 4（封顶 `+1`），`p=4` 走 case 3（`+q−1=+2`），结果不同——说明 `p` 真实参与展开。

## 2. ε_ωSS（无参数 `p`，**无** case 4）

### 2.1 case 2 (`q=1`)：`A=(1,2)`
- `n=2`；`br=1`；`L=1`；`q=1` → case 2。
- `expand(A,2)`：`M=1`。末位 −1 `(1,1)`；`s=1`（case 2）：`X=1+2−1=2`，运行 `[1,1]` 第 2 项 = 1 → 追加 **1** → `(1,1,1)`。
- 结果：`expand(A,2) = (1,1,1)`。

### 2.2 case 3（`q≥2`，不封顶）：`A=(1,1,3)`
- `n=3`；`br=2`；`L=1`；`q=2` → case 3，`add=1`。
- `expand(A,2)`：`M=1`。末位 −1 `(1,1,2)`；`s=1`（case 3）：`X=3`，运行 `[1,1,2]` 第 3 项 = 2，`+1` → 追加 **3** → `(1,1,2,3)`。
- 结果：`expand(A,2) = (1,1,2,3)`。

### 2.3 case 3 大跳：`A=(1,4)`
- `n=2`；`br=1`；`L=1`；`q=3` → case 3，`add=q−1=2`（不封顶）。
- `expand(A,2)`：`M=1`。末位 −1 `(1,3)`；`s=1`（case 3）：`X=2`，运行 `[1,3]` 第 2 项 = 3，`+2` → 追加 **5** → `(1,3,5)`。
- 结果：`expand(A,2) = (1,3,5)`。
- 对照 ε_pSS `p=1` 的同输入 `(1,4)`（§1.4）得 `(1,3,4)`：ε_ωSS 因不封顶而跳到 5，二者不同——印证 ε_ωSS = ε_pSS 的 `p→ω` 极限。

# GoogologyLib

多语言大数符号库 (Multi-language Googology Notation Library).

Each language branch contains only the implementation for that language:

| Branch | Language | Status |
|--------|----------|--------|
| `C++` | C++ | Core framework + Knuth + Conway |
| `C` | C | Core framework + Knuth + Conway |
| `C#` | C# | Core framework + Knuth + Conway |
| `Rust` | Rust | Core framework + Knuth + Conway |
| `java` | Java | Core framework + Knuth + Conway |
| `python` | Python | Core framework + Knuth + Conway |
| `Lean4` | Lean4 | Core framework + Knuth + Conway |
